Projets pratiques

1. VPN IPsec site-à-site avec pfSense

Objectif : étudier l'interconnexion sécurisée de deux réseaux locaux distants à travers un tunnel VPN IPsec.

Environnement : pfSense, VMware, deux réseaux locaux virtuels.

Travaux réalisés ou étudiés :

- Mise en place de deux pare-feu pfSense.
- Configuration des interfaces WAN et LAN.
- Paramétrage des phases 1 et 2 d'IPsec.
- Configuration des règles de filtrage.
- Diagnostic de connectivité et tests de communication entre les réseaux.

Documentation et résultats : "Consulter le laboratoire VPN" (https://github.com/yanniskenmoe2-afk/VPN_SITE-TO-SITE_LAB)

2. Segmentation VLAN et routage inter-VLAN avec Huawei eNSP

Objectif : segmenter un réseau local et permettre une communication contrôlée entre plusieurs VLAN.

Travaux réalisés :

- Création et configuration des VLAN.
- Affectation des ports aux VLAN.
- Configuration du routage inter-VLAN avec les interfaces VLANIF.
- Vérification de la connectivité entre les réseaux.

Technologie : Huawei eNSP.

Documentation : "Découvrir le projet Huawei" (https://github.com/yanniskenmoe2-afk)

3. Réseau Cisco : VLAN, DHCP, relais DHCP et ACL

Objectif : mettre en place un réseau segmenté avec attribution automatique des adresses IP et filtrage des communications.

Travaux réalisés :

- Création de quatre VLAN : 10, 20, 30 et 40.
- Configuration des pools DHCP sur le routeur central.
- Mise en place d'un relais DHCP sur un autre routeur.
- Routage inter-VLAN de type Router-on-a-Stick.
- Utilisation des ACL pour contrôler l'accès à certains services réseau.

Technologie : Cisco Packet Tracer.

Documentation : "Retrouver le projet Cisco" (https://github.com/yanniskenmoe2-afk)
